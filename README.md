 ONG Sabedoria e Alegria — Relatório Técnico (Etapa3)
 Descrição do Projeto
 
 Este projeto consiste na criação de um site institucional interativo para a ONG Sabedoria
 e Alegria, desenvolvido como parte da disciplina de Desenvolvimento Front-End para Web
 do curso de Análise e Desenvolvimento de Sistemas (ADS) da Cruzeiro do Sul. O site tem
 como objetivo apresentar a organização, divulgar seus projetos sociais e facilitar o
 cadastro de voluntários e doadores.
 
 Tecnologias Utilizadas-
 - HTML5: estrutura semântica do conteúdo;
 - CSS3 (Flexbox e Grid): layout responsivo e design moderno;
 - JavaScript (ES6): interatividade, máscaras, validação e roteamento SPA;
 - Git e GitHub Pages: versionamento e hospedagem do site.
 
 Estrutura de Pastas
 index.html
 assets/css/style.css
 assets/js/router.js
 assets/js/validation.js
 assets/js/mask.js
 
 Navegação e Interatividade
 O site utiliza um menu responsivo com submenu dropdown e navegação SPA, permitindo
 transição entre seções sem recarregar a página. O formulário de cadastro conta com
 validações, máscaras e modal de feedback.
 
 Formulário de Cadastro
 Campos: Nome, E-mail, CPF, Telefone, Data de Nascimento, CEP, Endereço, Cidade e
 Estado.
 Validação de e-mail e CPF, máscaras de entrada e mensagens de erro dinâmicas.
 
 Sistema de Design
 Paleta de cores: primária (#76c7c0), secundária (#4CAF50), neutros (#ffffff, #f8fbff).
 Hierarquia visual: 5 tamanhos de fonte, espaçamentos modulares e layout baseado em
 Grid e Flexbox.
 
 Responsividade
 Layout adaptável para smartphones, tablets e desktops (mobile-first). Breakpoints
 definidos para 480px, 768px, 992px e 1200px.
 Requisitos Atendidos- Estrutura HTML5 semântica.
- Responsividade total.- Acessibilidade básica (labels, alt, navegação por teclado).- Validação e máscaras em formulários.- Modal interativo.- Organização de pastas clara.

 Conclusão
 A terceira etapa do projeto consolidou os conhecimentos em HTML, CSS e JavaScript,
 com foco em responsividade, interatividade e boas práticas semânticas. O resultado é um
 site institucional funcional e acessível que reflete o propósito da ONG Sabedoria e
 Alegria: transformar vidas através da solidariedade.
